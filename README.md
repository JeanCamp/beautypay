# 🎉 Controle de Comissões - Sistema Completo

Sistema web moderno para controle de comissões de profissionais de beleza.

## 🚀 Como Começar

### 1. Instalar Dependências
```bash
npm install
```

### 2. Executar o Sistema
```bash
npm run dev
```

Acesse: **http://localhost:3000**

## ✨ Funcionalidades

- ✅ **Registro de Atendimentos** - Cálculo automático de comissão
- ✅ **Dashboard** - Estatísticas em tempo real
- ✅ **45 Serviços Pré-Cadastrados** - Com porcentagens configuradas
- ✅ **Histórico Completo** - Filtros e busca
- ✅ **Fechamento de Dia/Quinzena** - Controle de pagamentos
- ✅ **Relatórios com Gráficos** - Análise detalhada
- ✅ **Metas e Projeções** - Acompanhamento de objetivos
- ✅ **Exportação** - CSV, Excel e PDF
- ✅ **Dark Mode** - Interface clara/escuro
- ✅ **Mobile-First** - Funciona perfeitamente no celular

## 📱 Primeiro Acesso

1. Cadastre seu usuário
2. Configure seu nome e metas
3. Comece a registrar atendimentos

## 💾 Dados

Os dados são salvos no navegador (localStorage) e persistem mesmo após fechar o navegador.
